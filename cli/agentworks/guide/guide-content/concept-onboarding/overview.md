## Security disclosure

An agent managing Agentworks gains access to everything Agentworks can reach: every managed resource
and secret reference, plus anything accessible over SSH from the operator's workstation. Use the
strictest practical harness approval and sandbox settings, especially for a real installation. Guide
instructions describe boundaries; they never grant consent.

Bootstrap-specific links to each harness's approval and sandbox settings land with the Phase 3
bootstrap packages. Phase 1 names the required posture without inventing those links early.
