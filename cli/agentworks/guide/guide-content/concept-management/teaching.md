Read a bare kind topic to see its current members. Read a kind/name topic for origin, enablement,
readiness, relationships, and live-instance references.

Create and change declarable resources through their owning CLI commands or canonical manifests,
then read the matching kind/name topic to confirm the projected state. Discover a capability in the
implementation inventory before adopting it; disabled and not-ready implementations require an
explicit operator decision, not automatic enablement.

After an upgrade, resolve emitted deprecation instructions before changing unrelated state. For a
failure, begin with the framed error and projected readiness. Run `agw doctor` only after consent to
examine the workstation, and authorize any repair separately.
