The base topic selects the installed distribution version. Exact historical topics each render one
locally packaged section, so a multi-release question uses the ordered applicable topics without
rendering the complete changelog. Rendering is offline.

Use `read-release-notes` only when the exact requested version or range is absent locally. The
operator supplies both ends of the inclusive range. The action is limited to the canonical
Agentworks GitHub releases page, follows no embedded link, and has an inert refusal path. A current
capability or adoption question belongs to `concept-onboarding`, not to an inferred release delta.
